# Bike Sharing Demand with AutoGluon

Predicts hourly bike rentals for the Kaggle Bike Sharing Demand competition with AutoGluon. It compares raw features, feature engineering, and feature engineering with hyperparameter tuning.

## What's inside

- `project-template.ipynb` has the full workflow
- `report-template.md` is the written report
- `train.csv` and `test.csv` are the competition data

## How to run

```bash
pip install -r requirements.txt
jupyter notebook project-template.ipynb
```

The download and submission cells need your own Kaggle API credentials; without them, skip those cells and the credentials cell.
